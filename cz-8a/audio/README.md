## 生成占位配音的方式

如果暂时没有真人录音，可用任意 TTS（文本转语音）工具生成中文女声/男声 MP3，
按上表文件名保存即可。建议采样率 44.1kHz、单声道、比特率 128kbps，以控制体积。

程序同时通过 Web Audio 振荡器合成了低频引擎轰鸣（跟随一/二级推力自动变化），
该效果无需任何音频文件。
