# 🐮 牛来跑酷 · Niu Li Parkour

以影片《牛来》主角 **牛来**（小牛犊）为默认形象的**横向**三跑道网页跑酷游戏：角色在屏幕左侧从左向右奔跑，障碍与金币从右侧迎面而来；上/中/下三条跑道带近大远小的纵深。纯原生 HTML5 Canvas + Web Audio 实现，**零依赖、双击 `index.html` 即玩**。

## 🎮 玩法

| 项目 | 说明 |
|---|---|
| 🪙 金币 | 每枚 **+1 分** |
| 🍎 苹果 | 吃到后**加速**，且 **10 秒内每枚金币 +10 分**；再吃苹果可**叠加**时长（上限 30s） |
| 🚧 障碍 | 撞上即结束；地面障碍（倒木/路障/仙人掌/雪人/栅栏…）需**跳**或换道绕开，悬挂障碍（树枝/限高杆/冰凌/雁阵…）需**滑铲**钻过 |
| 🛤️ 跑道 | 上/中/下三行，远小近大，可随时切换 |
| ⚡ 难度 | 简单 / 正常 / 困难 -- 决定基础速度、提速曲线与障碍密度 |

## 🕹️ 操作

- **电脑**：`W/↑` 上道 · `S/↓` 下道 · `空格/J` 跳跃 · `K/X/Shift` 滑铲（空中按下滑键=急坠）· `P/Esc` 暂停 · 鼠标点画面也可跳
- **手机**：上/下滑切道 · 点按跳 · 左滑或"滑"按钮滑铲，另有 ▲▼/跳/滑 屏幕按钮

## 🐾 角色（8 位）

牛来（默认）· 牛来妈妈 · 云雀 · 蛇 · 豹拉 · 狼 · 牛二 · 牛爸爸

所有角色均以 Canvas 矢量手绘（正面用于选择界面，背面用于奔跑），体型、花色、犄角、尾巴、表情各不相同。

## 🎽 跑酷装扮（每类 6 种风格 + 自然款）

- **帽子**：运动帽 / 牛仔帽 / 草帽 / 小皇冠 / 花环 / 绒球帽
- **衣服套装**：运动背心 / 红围巾 / 英雄披风 / 探险夹克 / 彩虹卫衣 / 绅士礼服
- **鞋子**：蓝跑鞋 / 疾风红鞋 / 黄雨靴 / 登山靴 / 轮滑鞋 / 星光鞋

装扮为外观搭配，所有角色通用，实时预览。

## 🏞️ 赛道（5 种）

森林 · 城市 · 沙漠 · 雪山 · 草原 —— 每种赛道有专属天空、远景、路旁景物、路面风格与 3 种专属障碍物，另有环境粒子（落叶/沙尘/飘雪/花瓣）。

## 📁 结构

```
├── index.html        页面骨架 / HUD / 菜单 / 弹窗
├── css/style.css     田园玩具风 UI
└── js/
    ├── core.js       工具函数 + WebAudio 音效/音乐
    ├── chars.js      8 位角色矢量绘制（正/背面 + 动画）
    ├── outfits.js    装扮系统（帽子/衣服/鞋子）
    ├── tracks.js     5 种赛道主题（背景/景物/障碍）
    ├── game.js       横向引擎：三行纵深跑道、跳/滑、碰撞、粒子、难度
    ├── menu.js       菜单/HUD/弹窗交互与本地存档
    └── main.js       启动入口
```

## 📱 移动端适配

- **竖屏**：按宽度自适应，保证前方 ≥14 个世界单位（约 1.7 秒反应距离）的可视跑道，障碍/金币一律从屏幕右缘进入；场景带垂直居中，天空与草坡自动向上下延伸
- **横屏**：设置菜单整页可滚动，矮屏下自动切换紧凑布局（角色 8 格单行、装扮横向滑动、精简预览卡），全部设置项均可查看与操作

## 💾 存档

选择与各难度最佳纪录保存在 `localStorage`，菜单与结算界面展示“新纪录”。
